# Internationalization contract

Site Manager is English/Spanish from the WordPress adapter onward.

## Rules

- English is the source and fallback language for product strings.
- The WordPress adapter follows the current administrator locale, not the public-site locale.
- Every `es_*` WordPress locale uses the bundled neutral Spanish catalogue (`site-manager-es_ES.mo`).
- Presentation strings are translated at render time.
- Stored discovery snapshots, capability identifiers, scopes, blocker contracts and MCP/REST machine payloads stay canonical and language-neutral. Changing the administrator language must never require rediscovery or mutate stored governance state.
- Future platform adapters (PrestaShop and others) must follow the same boundary: machine contracts remain stable; each UI adapter localizes presentation independently.

## WordPress release contents

The installable ZIP must include:

- `languages/site-manager-es_ES.po`
- `languages/site-manager-es_ES.mo`

CI verifies that the Spanish catalogue is present, compiled, and that critical dashboard/governance strings are translatable.
