# Site Manager 0.4.0 acceptance

SM-3A.4 introduces the first evidence-backed semantic SEO writer for the controlled `seo-geo-theme` provider.

## Contract

- The provider must be the resolved, non-conflicting SEO authority.
- Bounded source inspection must prove native WordPress post/permalink inputs.
- No SEO-specific post-meta storage may be detected for the provider.
- ACF, theme-mod and custom-database ownership must be absent.
- Directly governable inputs are intentionally limited to:
  - `title` -> `post_title`
  - `description` -> `post_excerpt`
- Canonical, robots, Open Graph, schema, hreflang and sitemap remain derived outputs unless a future provider contract proves a dedicated reversible source.
- All writes require plan -> explicit confirmation -> stale-target guard -> apply -> verify -> rollback.

## Nuevaweb acceptance

After installing 0.4.0 on the controlled EMMake clone, Site Manager should report `seo.write` as governable, show semantic-native write mode, expose `title` and `description` as governable SEO inputs, and report zero governance gaps for the currently detected WordPress surfaces. Remote authorization remains separate and should still be zero until a write scope is explicitly granted.
