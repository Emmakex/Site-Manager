# SM-4F Command Gateway note

This note documents the read-only GitHub Command Gateway slice added after Site Manager 0.11.3. It does not change the WordPress plugin version.

The canonical managed path is:

```text
ChatGPT → GitHub → Command Gateway → production MCP → Site Manager → WordPress → sanitized result → GitHub → ChatGPT
```

The first slice exposes only `site.read` and `site.diagnostics` as registered business actions. Production MCP endpoint and bearer remain outside command files and are supplied by a per-site protected GitHub Environment.

See `ENGINEERING_RULES.md` and `docs/COMMAND_GATEWAY.md`.
